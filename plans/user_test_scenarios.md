## 1. Сценарии веб-интерфейса (Flask)

**Предусловие:** Браузер открыт на странице `http://localhost:5000/`

   - ID сотрудника: `E001`
   - Пароль: `SecurePass123!`

3. Нажать кнопку "Зарегистрироваться"

**Ожидаемый результат:**

- ✅ Появляется сообщение "Регистрация успешна!"
- ✅ Страница перенаправляет на страницу входа

## 4. Сценарии управления задачами

### Сценарий 4.1: Полный цикл задачи (сотрудник)

**Предусловие:** 
- Пользователь (сотрудник) вошёл в мобильное приложение
- На списке задач видна новая задача со статусом "NEW"

**Шаги:**
1. Нажать на задачу для открытия карточки
2. На карточке нажать "Изменить статус" → выбрать "IN_PROGRESS" → "Сохранить"
3. Выполнить работу по задаче (имитация: ждём 5 сек)
4. Вернуться в приложение
5. Нажать на ту же задачу → "Изменить статус" → выбрать "DONE" → "Сохранить"

**Ожидаемый результат:**
- ✅ Первое изменение: статус → IN_PROGRESS (на сервере обновлена `task_status`)
- ✅ Второе изменение: статус → DONE (на сервере `completed_at` заполнено текущей датой/временем)
- ✅ На дашборде менеджера тепловая карта обновляется:
   - Количество активных задач для сотрудника уменьшилось на 1
- ✅ Задача больше не отображается в списке "Мои активные задачи"

**Предусловие:**

4. Нажать "Сохранить"

**Ожидаемый результат:**
